### 🕵️ A Little About Me

I got into cybersecurity because I wanted to know *how* things break — not just that they do. Now I spend my time poking at web apps, chasing SQL injections, and figuring out how attackers think, so one day I can help stop them for real.

Still early in the journey, still learning every day — but every vulnerability I find teaches me something a textbook never could.
